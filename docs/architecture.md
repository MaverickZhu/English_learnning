技术架构与模块边界

一、整体架构
- Web：React + Vite
- App：React Native
- Backend：FastAPI（Python）
- 数据库：PostgreSQL
- 媒体存储：MinIO（对象存储）

二、模块边界
1. 内容与资源服务
   - 词汇、句子、文章
   - 图片、音频元数据
   - 标签与等级体系
2. 学习进度服务
   - 学习记录
   - 掌握度模型
   - 复习提醒
3. 练习与测试服务
   - 题型配置
   - 评分与解析
   - 模拟考试
4. 用户与权限
   - 账号与设备
   - 同步与偏好设置

三、数据模型概览
- Word：词形、释义、例句、音频、图片、等级、标签
- Sentence：文本、结构标注、音频、图片、等级、标签
- Passage：段落结构、关键词、音频、图片、等级、标签
- Exercise：题型、题干、选项、答案、解析
- Exam：题型组合、评分规则、时间限制
- StudyRecord：用户、内容、时间、得分、掌握度

四、媒体与语音策略
- 语音：支持 TTS 与预制音频并存
- 图片：语义标签+内容绑定，支持多图推荐

五、前后端交互
- REST API 为主，数据结构按内容模型统一
- 统一响应与错误码，支持分页与增量加载
