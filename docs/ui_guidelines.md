UI 风格与设计规范

一、风格定位
- 现代、清爽、教育感、轻科技
- 视觉强调内容理解与学习效率

二、色彩体系
- 主色：#2F6BFF（可信与专注）
- 辅色：#22C55E（正向反馈）
- 强调：#F59E0B（提示与警示）
- 背景：#F5F7FB
- 文本主色：#0F172A
- 次级文本：#64748B

三、字体与排版
- 标题：Semibold，层级清晰
- 正文：Regular，行高 1.5
- 数字与统计：Medium

四、布局规范
- Web：12 栏网格，卡片化布局
- App：单列主布局，强调操作主按钮
- 留白充足，内容密度中等

五、组件规范
- 学习卡片：标题 + 释义 + 音频按钮 + 配图
- 练习题卡：题干 + 选项 + 解析折叠
- 进度组件：环形或条形进度
- 结果报告：得分、能力雷达、建议列表

六、图片与插图
- 主题明确、风格统一
- 支持实拍与插画混合，避免过度装饰
- 优先匹配语义而非装饰性

七、动效规范
- 反馈动效简短，强调完成感
- 页面切换轻微过渡，避免干扰学习
