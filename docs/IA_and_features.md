信息架构与功能清单

一、信息架构（IA）
- 首页
  - 今日目标
  - 今日学习进度
  - 快捷入口（学习/练习/测试）
- 学习
  - 单词学习
  - 句子学习
  - 文章学习
- 练习
  - 图片选义
  - 听力辨音
  - 句子排序
  - 完形填空
- 测试
  - 单元测试
  - 阶段测试
  - 考级模拟
- 学习管理
  - 学习计划
  - 历史记录
  - 错题本
  - 掌握度
- 个人中心
  - 账号与设置
  - 设备与同步

二、功能清单（按模块）
1. 学习模块
   - 语音播放（句子/文章段落级）
   - 单词多义项与例句
   - 关键词解释与高亮
   - 图片语义匹配（词义/句意/文章含义）
2. 练习模块
   - 图片选义：多图择一
   - 听力辨音：选择正确单词或句子
   - 句子排序：打乱排序恢复语序
   - 完形填空：词汇或语法填空
3. 测试模块
   - 题型配置：题量、时间、分值
   - 自动评分与解析
   - 能力分布与建议
4. 学习管理
   - 计划：每日/每周目标
   - 进度：学习时长、完成率
   - 错题：归类与复习提醒
5. 内容管理（后台）
   - 词/句/文统一内容模型
   - 语音、图片资源管理
   - 标签与等级体系管理
