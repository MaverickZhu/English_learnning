在线英语学习平台 PRD 大纲

一、背景与目标
- 为独立开发者打造可持续迭代的英语学习产品，覆盖 Web 与移动端。
- 通过语音播放与配图强化语义理解，提升学习效率与记忆保持。

二、用户画像
- 学生与备考人群：需要系统化学习与考级模拟。
- 职场与成人学习者：偏向场景化、碎片化学习。
- 初学者：更依赖语音与图片辅助理解。

三、核心价值
- 语音 + 图片 + 语义结构的多通道输入。
- 学习、练习、测试全闭环。
- 学习路径与内容等级可配置。

四、核心功能清单
1. 学习模块
   - 单词学习：发音、释义、例句、配图、同反义词
   - 句子学习：语音播放、结构标注、配图理解
   - 文章学习：段落语音、关键词释义、配图
2. 练习模块
   - 图片选义
   - 听力辨音
   - 句子排序
   - 完形填空
   - 跟读打分（可延后上线）
3. 测试与模拟
   - 单元测试与阶段测试
   - 考级模拟：题型比例、限时机制、结果报告
4. 学习管理
   - 学习计划与目标
   - 学习历史与掌握度
   - 错题本与复习提醒

五、学习流程
- 选择等级与主题
- 学习单元内容（词/句/文）
- 进入练习与测试
- 查看报告并复习薄弱项

六、内容体系
- 等级：A1-C1 或按考试等级
- 主题：校园、旅行、职场、社交等
- 结构：单词 -> 句子 -> 文章

七、非功能需求
- 低延迟语音播放
- 离线缓存能力（App 优先）
- 多端一致体验
- 内容可扩展，支持后台配置

八、版本里程碑
- V1：核心学习与基础练习、基础测试
- V1.1：考级模拟与学习管理增强
- V1.2：跟读打分与内容扩展
